# BinderFlow Roadmap

## v0.1 — TCG Inventory Foundation

Goal: provide a fast, reliable inventory system for card singles inside Wix.

### Catalogue
- Games
- Sets
- Cards
- Card variants
- Languages
- Finishes: normal, foil and other game-specific finishes
- Rarity
- Card number
- Images and external catalogue identifiers

### Inventory
- Quantity
- Condition
- Acquisition cost
- Selling price
- SKU
- Notes
- Binder / storage location
- Inventory status

### Binder management
- Binder creation
- Page numbering
- Slot positioning
- Search by physical location
- Move cards between locations
- Basic inventory audit

### Dashboard
- Inventory overview
- Search
- Filters
- Add/edit inventory
- Low-stock and missing-location indicators

---

## v0.2 — Wix Stores Sync

Goal: publish owned inventory to Wix without importing the entire global card catalogue as Wix products.

- Create Wix products from inventory
- Link BinderFlow inventory records to Wix product IDs
- Sync price
- Sync quantity
- Sync images and metadata
- Unpublish items when appropriate
- Handle Wix-side sales and stock changes

---

## v0.3 — POS

Goal: provide a card-store-oriented sales workflow.

- Fast card search
- Barcode / SKU input
- Cart
- Quantity controls
- Customer selection
- Discounts
- Checkout handoff / Wix order creation
- Automatic inventory decrement
- Receipt/order reference
