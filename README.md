# BinderFlow

**TCG Inventory & POS for Wix**

BinderFlow is a Wix application for trading card game stores. It adds TCG-specific inventory, binder locations, pricing, buylist and point-of-sale workflows on top of Wix.

## Vision

A store should be able to manage thousands of singles without treating the full TCG universe as Wix products.

BinderFlow separates:

- the global card catalogue;
- the store's owned inventory;
- physical binder/storage locations;
- Wix products that are actually published for sale.

## Initial scope

### v0.1 — TCG Inventory

- Games
- Sets
- Cards
- Variants
- Conditions
- Inventory quantities
- Selling price and acquisition cost
- Binder / page / slot location
- Basic search and filters
